# Password Strength Analyzer 🔐

A Python tool that evaluates the strength of user-entered passwords.

## 📌 Features
- Check password length (minimum 8 characters)
- Detect uppercase, lowercase, digits, and special characters
- Rate passwords as **Weak**, **Moderate**, or **Strong**
- Simple and beginner-friendly code

## 🚀 Installation & Usage
1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/password-strength-analyzer.git
## Navigate into the project folder:

## bash
cd password-strength-analyzer
Run the script:

## bash
python password_strength.py
Enter a password when prompted to see its strength rating.
